# Gallery Spec — AndyAI Visual Studio v0.1

## Purpose

The Gallery is the main product surface. Users browse, search, preview, and select templates.

## Gallery Card Fields

- Template ID
- Template name
- Category
- Style family
- Recommended format
- Best for
- Free / Pro badge
- Preview button
- TAP button

## Filters

- Search by keyword
- Search by template ID
- Category
- Style family
- Format
- Audience
- Project type
- Free / Pro

## Sort Options

- Featured
- Newest
- Most used
- By template ID
- By category

## Empty State

No templates found. Try another keyword or browse all categories.

## TAP CTA

Each card must include a strong button:

```text
TAP Template
```
