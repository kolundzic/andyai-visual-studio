# Release Notes — v0.5.0 Live Supabase Client Wiring

## Summary

v0.5.0 turns the v0.4.0 Supabase data model into a live client-ready product layer.

- Environment template for mock/live Supabase mode.

- Supabase adapter for `avs_templates`.
- Adapter switch with safe fallback to local mock data.
- Live data-ready Gallery route.
- Live data-ready Template Detail route.
- Live data-ready TAP Editor route.
- Enhanced `/data-preview` route with source visibility.
- Verification script for v0.5.0.
