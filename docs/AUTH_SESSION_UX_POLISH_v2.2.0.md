# v2.2.0 — Auth Session UX Polish

## Purpose

Make the authentication layer easier to understand before the product enters public beta.

## Rules

1. Public demo pages must not require login.
2. Workspace pages may be protected later, but must remain explainable now.
3. Auth configuration must be visible in docs and environment setup.
4. Fallback behavior must be intentional, not accidental.

## Beginner Explanation

Authentication is the gate. Session UX is the way the user understands whether the gate is open, closed, or running in demo mode.
