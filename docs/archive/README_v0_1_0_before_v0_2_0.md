# 🅰️ AndyAI Visual Studio

**Version:** v0.1.0  
**Status:** SaaS Scaffold  
**Product Type:** Public SaaS / Visual Template Studio  
**Source Library:** `andyai-visual-template-system`

AndyAI Visual Studio is a professional SaaS product for browsing, customizing, and using reusable academic sci-fi visual templates.

It turns the AndyAI Visual Template System into a public product:

```text
Landing Page → Gallery → Template Detail → TAP Editor → Final Prompt / Export / Generate → Dashboard → Paid Plan
```

## Core Promise

Stop starting visuals from zero.  
Choose a proven visual template, customize it, and create professional diagrams, posters, dashboards, and explainers in minutes.

## Stack

- Next.js / Vercel
- Supabase
- Stripe later
- Template sync from `andyai-visual-template-system`
