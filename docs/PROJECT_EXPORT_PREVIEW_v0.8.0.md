# Project Export Preview v0.8.0

## Route

`/projects/[projectId]/exports`

## Purpose

This route gives each project a focused export preview page.

It shows:

- project title
- copy prompt action
- saved export records
- JSON payload preview
- export timestamps

## Why it matters

A SaaS product must not only create records. It must help users recover and reuse their work.

Export preview is the first step toward:

- downloadable prompt packs
- JSON exports
- Markdown exports
- HTML/SVG visual exports
- provider handoff to image/video tools
