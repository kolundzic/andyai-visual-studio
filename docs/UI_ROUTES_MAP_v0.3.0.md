# UI Routes Map — v0.3.0

| Route | Page | Role |
|---|---|---|
| `/` | Landing | Explains the SaaS value and sends users into Gallery or TAP Editor. |
| `/gallery` | Gallery | Lets users browse and search visual templates. |
| `/templates/[templateId]` | Template Detail | Shows one template, use case, prompt seed, and editor entry. |
| `/tap-editor` | TAP Editor | Converts a selected template and user goal into structured prompt output. |
| `/pricing` | Pricing | Shows the future monetization model. |
| `/dashboard` | Dashboard | Previews the future logged-in workspace. |

━━━━━━━━━━━━━━━━━━━━

## Canonical User Journey

1. User lands on the homepage.
2. User opens Gallery.
3. User finds a template by ID, category, or keyword.
4. User opens Template Detail.
5. User sends the template into TAP Editor.
6. User edits the goal.
7. User exports or saves the prompt in a later version.
8. User upgrades when paid features are introduced.
