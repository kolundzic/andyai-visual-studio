# v0.3.0 Frontend Product Shell Release

**Release:** `v0.3.0`  
**Type:** Frontend product shell upgrade  
**Repo:** `andyai-visual-studio`

━━━━━━━━━━━━━━━━━━━━

## Release Summary

This release establishes the first visible SaaS shell for AndyAI Visual Studio.

It introduces a complete navigable product skeleton:

- Landing
- Gallery
- Template Detail
- TAP Editor
- Pricing
- Dashboard

It also creates the first reusable component inventory and seed template data layer.
