# v5.8.0 — Client Delivery Package

## Purpose

Create the agency-ready delivery layer for client handoff.

## Adds

- Client Delivery Package route

- Delivery package library contract

## Canon

Agency work is not finished when an artifact is generated. It is finished when it is packaged, reviewed, approved, and delivered.
