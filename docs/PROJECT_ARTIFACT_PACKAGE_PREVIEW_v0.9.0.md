# Project Artifact Package Preview v0.9.0

## Route

`/projects/[projectId]/package`

## Purpose

The package route gives the user a focused screen for reviewing downloadable project outputs.

It shows:

- project title
- export count
- active data mode
- downloadable TXT file
- downloadable Markdown file
- downloadable JSON package
- file manifest

## Why this matters

The export package preview is the bridge between SaaS workspace and external use.

It prepares the product for:

- provider handoff
- ZIP package generation
- visual generation APIs
- client delivery
- evidence bundles
- downloadable project archives
