## Product meaning

AndyAI Visual Studio is now positioned as a practical SaaS studio for reusable AI visual production systems.

The MVP chain is:

```text
Template → TAP Editor → Project → Export → Package → Download
```

## Public demo story

The public demo should show a simple, understandable path:

1. Open the home page.
2. Browse visual templates.
3. Open a template.
4. Send it to the TAP Editor.
5. Save as a project.
6. Preview the project package.
7. Copy or download the final prompt artifact.

## Canonical line

> AndyAI Visual Studio turns reusable visual intelligence into editable prompts, saved projects, and downloadable artifact packages.
