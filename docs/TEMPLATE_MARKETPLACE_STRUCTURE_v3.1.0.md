# v3.1.0 — Template Marketplace Structure

## Purpose

This release introduces the first marketplace structure for AndyAI Visual Studio.

## Adds

- `/marketplace`
- `MarketplaceHero`
- `marketplaceTemplates`
- marketplace principles
- reusable template metadata structure

## Canonical Rule

A visual template is not only a prompt. It is a reusable product unit with metadata, category, usage intent, and export path.
