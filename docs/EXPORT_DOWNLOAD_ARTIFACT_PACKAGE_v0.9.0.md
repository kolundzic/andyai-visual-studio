# AndyAI Visual Studio v0.9.0
## Export Download & Artifact Package Layer

Status: canonical release layer  
Repo: `andyai-visual-studio`  
Version: `v0.9.0`  
Base: `v0.8.0`

## Purpose

v0.9.0 turns saved project exports into downloadable artifacts.

The user can now move from:

Template → TAP Editor → Save Project → Save Export

into:

Project → Package Preview → Download TXT / Markdown / JSON

## Added

- TXT prompt download
- Markdown prompt download
- JSON artifact package download
- export metadata builder
- project package preview route
- package preview component
- single export download buttons
- package links from project and export pages
- export format documentation
- Supabase migration for download format and artifact metadata

## Product meaning

A SaaS product becomes more real when the user can take work out of the system.

v0.9.0 gives AndyAI Visual Studio the first complete artifact handoff layer.

## Canonical formula

Prompt is edited. Export is saved. Artifact is downloaded. Package becomes reusable evidence.
