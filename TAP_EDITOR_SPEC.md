# TAP Editor Spec — AndyAI Visual Studio v0.1

## Purpose

The TAP Editor turns a template into an editable working prompt.

## Core Fields

- Project name
- Topic
- Audience
- Visual type
- Style family
- Format
- Language
- Required labels
- Main flow / logic
- Evidence or governance layer
- Avoid section

## Editor Panels

### Left Panel
Editable fields.

### Center Panel
Generated final prompt.

### Right Panel
Template info, quality checklist, export controls.

## Actions

- Generate Prompt
- Copy Prompt
- Export Markdown
- Export JSON
- Save to Dashboard
- Generate Visual later

## Quality Gate

Before final export, show:

- Purpose present
- Audience present
- Labels locked
- Style selected
- Constraints included
- Format selected
