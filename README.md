## 1. What this product is

**AndyAI Visual Studio** is the public SaaS layer for reusable AI visual production systems.

It is designed for people who want to create polished AI visual outputs without starting from a blank prompt every time.

Instead of improvising, the user chooses a reusable visual template, edits the intent, adjusts the style and constraints, and exports a structured prompt or workflow.

The product sits on top of the AndyAI visual ecosystem:

- `andyai-visual-template-system`
- `andyai-visual-canon`
- `andyai-visual-factory`
- `andyai-visual-artifact-stack`

---

## 2. Product flow

```text
Hero → Gallery → Template Detail → TAP Editor → Prompt/Export → Pricing → Dashboard
```

### Plain meaning

1. The landing page explains the product clearly.
2. The gallery lets users browse templates.
3. The template detail page shows what the template is for.
4. The TAP Editor lets the user adapt the template.
5. The user exports a prompt, workflow, or project artifact.
6. Paid plans unlock higher limits and professional workflows.
7. The dashboard stores user projects, exports, and saved templates.

## 3. Core modules

| Module | Purpose |
|---|---|
| Hero | Clear public explanation and conversion entry point |

| Template Detail | Preview, use case, prompt logic, examples |
