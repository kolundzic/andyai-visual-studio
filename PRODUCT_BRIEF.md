# Product Brief — AndyAI Visual Studio v0.1

## One-line Definition

AndyAI Visual Studio is a professional AI visual template studio for serious diagrams, posters, dashboards, evidence cards, academic explainers, and product visuals.

## Problem

People waste time starting visual prompts from zero. They do not know how to structure diagrams, lock exact labels, choose a coherent style, or create reusable visual systems.

## Solution

AndyAI Visual Studio provides a searchable library of reusable master templates with exact prompt structures, style families, editable fields, and TAP-style customization.

## Core User Flow

```text
User lands on Home
→ understands the product from the hero
→ opens Gallery
→ searches by template ID, keyword, category, style family, project type
→ opens Template Detail
→ clicks TAP
→ edits fields in TAP Editor
→ gets final prompt / JSON / Markdown / future generated visual
→ saves/export under account
→ upgrades for serious usage
```

## Differentiation

This is not a simple prompt marketplace.

It is a visual production system:

- Template ID
- Style family
- Use case
- Editable fields
- Negative constraints
- Project mapping
- Quality gate
- Export
- Reuse
- Saved workflow
